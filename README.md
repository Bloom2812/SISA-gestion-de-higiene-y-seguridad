# SISA-gestion-de-higiene-y-seguridad
Aplicacion web para la gestion de higiene y seguridad de la planta corinfar

## Salud Ocupacional

Los datos clínicos y de aptitud se almacenan exclusivamente en
`salud_clinica` y `aptitudes_ocupacionales`. La migración legacy finalizó y las
herramientas administrativas temporales fueron retiradas de producción.
